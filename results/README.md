# 측정 결과

아직 사용자 GB10에서 측정한 결과가 없습니다.

원시 실행 결과는 기본적으로 Git에서 제외된 `local/`에 저장합니다. 검토한 결과만 이 디렉터리에 추가합니다. 외부 공개 수치는 `docs/candidates.md`의 근거와 구분합니다.

공개 결과에는 run ID, 실제 장비/스토리지 조건, 모델/엔진 리비전과 해시, 프롬프트/평가 세트 버전, 요청 계획/시도/완료 수, 점수와 지연, 메모리/I/O/오류 및 제한 사항을 함께 적습니다. 성공 사례만 선별하지 않습니다.

조건별 최대치를 판정할 때 미평가·미완료·임계값 미정은 통과로 표시하지 않습니다.
