# 2026-11-12 · Strata · Qwen3.8-Flash-Next IQ3_S · 128K 컨텍스트

[64K 실행](../2026-11-12-strata-qwen38fn-iq3s-64k/)과 같은 체크포인트·엔진에서 **`--context 128k` 한 가지만 바꾼** 용량 시험입니다.
Strata 문서는 128K 초과를 시험하지 않았다고 적고 있으며, 128K 자체의 GB10 측정값은 문서에 없습니다.

| 항목 | 값 |
|---|---|
| KV 배치 (엔진 로그) | QSA 층마다 131,072칸 중 32,768칸을 GPU 메모리에, 나머지는 pinned RAM 1.55 GiB에서 스트리밍 |
| 메모리 | 기동 직후 시스템 사용 약 100 GiB / 가용 약 21 GiB, 82K 입력 처리 후 사용 107 GiB / 가용 13 GiB |

## 64K 설정과 비교 (같은 45K 입력)

| | 64K 설정 | 128K 설정 |
|---|---|---|
| 첫 처리 TTFT | 21.5초 | 31.3초 |
| 짧은 입력 decode (throughput) | 53.0~54.2 tok/s | 47.4~49.9 tok/s |

128K로 늘리면 **82K 입력을 처리할 수 있게 되는 대신**, KV 스트리밍 때문에 같은 입력의 첫 처리가 약 1.5배 느려지고 짧은 대화의 decode도 약 8% 느려졌습니다(각 3회 이하의 소표본).

## 한계

- prefill 중앙값(표)은 캐시 재사용 요청이 섞여 있어 낮게 보입니다. 첫 처리 값은 위 요약표를 보십시오.
- 82K 입력에서 이 needle 검색은 통과했지만 긴 문서 이해·추론 품질은 별도 평가가 필요합니다.
